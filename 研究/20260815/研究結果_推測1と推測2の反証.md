## 0. 要旨

> **推測 1 の交差ケースの手証明。**(中略)**これが定理 12 の範囲を全 turn に広げる最短経路である。**

を挙げていた。本研究はこの課題に決着をつけた。結論は **否定的**である。

1. **論文の補題 21 は誤りである。** 「交差ケースは `7 ≤ E ≤ 10`」という主張の上界側が成り立たない。
   正しくは **`E ≤ 26`**(定理 N4)であり、交差ケースは `E = 26`(turn 39)まで存在する。

   この誤った上界を根拠にしていたためである。**未検証域が広く残っていた。**

2. **推測 1 と推測 2 はいずれも偽である。** 反例を 2 つ構成し、独立実装で検証した(§5)。

3. **その代わり、成立範囲を完全に確定した。** 新しい還元定理(定理 N6)により、
   ゲートを通過する局面の値は**形状とラベルだけで決まる**有限の対象に落ちる。
   これを利用して `E ≤ 10` の**全形状**を尽くした(ラベル割当は補題 16 で 2 回の求解に帰着させ、
   その帰着自体も `E ≤ 8` の全ラベル割当の直接列挙で裏を取った)。結果は次のとおり。

   > **定理 N9(本研究の主結果)**
   > 制約(C) ∧ `G_A2` ∧ `G_T` ∧ `G_3` の下で
   > - **turn ≥ 55(`E ≤ 10`)ならば 厳密解 = R2**(完全検証により証明)

   それ以上は拡張できないことも同時に確定した。

5. **論文の証明済定理はどれも壊れていない。** 特に **定理 9(健全性)は無傷**である。

## 1. 新しい構造補題

以下すべて 制約(C) を仮定する。論文の記号(`h` = 柱の高さ、`T` = `{c : h(c) ≥ 2}`、
`N` = `{c : h(c) ≥ 1}`(非満杯な柱)、`K` = 唯一の高い柱)を引き継ぐ。
4×4 の柱の平面において「グリッドライン」とは 4 行・4 列・2 対角の **10 本**を指す。

> **補題 N1(空き 3 のラインは存在しない / 柱の高さは 3 になれない)**
> `G_A2` の下で、**どのラインも空きマスがちょうど 3 個ではない**。
> とくに垂直線(= 柱)を考えて、**すべての柱の高さは `h ∈ {0, 1, 2, 4}`** である。

**証明.** 空きマスが 3 個のラインは石をちょうど 1 個含む。その石の色を X とすると
そのラインは「X が 1 石・`opp(X)` が 0 石」であり、`G_A2` の定義に反する。
柱 c の垂直線は 76 本のラインの 1 本で、その空きマス数は `h(c)` に等しいから `h(c) ≠ 3`。∎

これは論文の系 A1 を「石の側」ではなく「空きマスの側」から言い直したものだが、
**柱の高さが 3 になれない**という帰結は論文に無く、以下すべての土台になる。
たとえば論文 補題 17 の `K` は、`G_A2` の下では必ず `h(K) = 4` である。

> **補題 N2(`T` の幾何)**
> `G_A2 ∧ G_3` の下で、**`T` はどのグリッドラインとも高々 2 点で交わる**。とくに **`|T| ≤ 8`**。

**証明.** グリッドライン `ℓ` に対応する段3 の水平線 `L3` の空きマス数は
`|ℓ ∩ T|` に等しい(補題 1 より、柱の段3 が空 ⟺ `h ≥ 2`)。
`= 4` は `G_3` が禁じ、`= 3` は補題 N1 が禁じる。よって `≤ 2`。
行は 4 本あり各行で高々 2 点だから `|T| ≤ 8`。∎

論文の補題 15 は「H4 ラインについて」の主張だったが、実際には**10 本すべて**について成り立つ。

> **補題 N3(非満杯柱の幾何)**
> `G_A2` の下で、**どのグリッドラインも `N` と 0・1・2・4 点で交わる**(3 点はない)。

**証明.** 段4 の水平線の空きマス数が `|ℓ ∩ N|`(段4 が空 ⟺ `h ≥ 1`)であることと補題 N1 による。∎

> **定理 N4(ゲートの有限性)**
> 制約(C) ∧ `G_A2` ∧ `G_T` ∧ `G_3` を満たす局面は **`E ≤ 26`(turn ≥ 39)**でしか存在しない。
> さらに、そこで可能な柱の高さベクトル(形状)は **ちょうど 1,742,694 通り**であり、
> `E = 26` を実現する形状は 84 通りである。

**証明.** 補題 N1 より `h ∈ {0,1,2,4}`、`G_T` より `h = 4` の柱は高々 1 本。
`t = |{h = 2}|`、`u = |{h = 1}|`、`k = |{h = 4}| ∈ {0,1}` とおくと `T = {h=2} ∪ {h=4}` なので
補題 N2 より `t + k ≤ 8`。`u + t + k ≤ 16` と合わせて

```
E = u + 2t + 4k ≤ (16 − t − k) + 2t + 4k = 16 + t + 3k ≤ 16 + (8 − k) + 3k = 24 + 2k ≤ 26.
```

形状数と最大値は `shape_enum.cpp` による完全列挙で確定した(§4 の表)。∎

> **系 N5(論文 補題 21 の訂正)**
> 論文の補題 21 の「交差ケースは `E ≤ 10`」は**誤り**である。
> 正しい上界は `E ≤ 26` であり、交差は `E = 26` でも起こる。

**理由.** 補題 21 の証明は「2 本の全空き H4 ラインが通る 7 本の柱」だけを数えており、
**その 7 本以外に非満杯な柱が無い**ことを暗に仮定している。この仮定に根拠は無い。
実際 `E = 26` の形状(たとえば下記)は 16 柱すべてが非満杯で、
全空き H4 ラインが **10 本**あり、そのすべてが互いに柱を共有する。

```
   h[y=4] : 4 2 1 1
   h[y=3] : 2 1 2 1
   h[y=2] : 1 2 1 2
   h[y=1] : 1 1 2 2      (E = 26, turn = 39)
```

論文 §11.1 は「補題 21 によりその場合は `7 ≤ E ≤ 10` に限られる」として
交差ケースの検証を turn 57 / 55 / 53 に限定していたので、**検証は範囲を尽くしていなかった**。
反例が turn 54 以下にあったのはこのためである。

## 2. 還元定理 —— ゲート通過局面は「形状 + ラベル」に潰れる

> **定理 N6(G_A2 局面の還元定理)**
> 制約(C) ∧ `G_A2` を満たす局面 P の値は、次の 2 つだけで決まる。
> 1. 柱の高さベクトル `h[0..15]`(形状)
> 2. 各空きマスに付いたリーチのラベル(黒 / 白)
>
> 石の並びのそれ以外の情報は値に一切影響しない。

**証明.** `G_A2` の下で、盤上の各ラインは空きマス数によって次のいずれかに分類される。

| 空き数 | 内容 | 以後の役割 |
|---|---|---|
| 0 | 石 4 個。決着していないので混色 | 死んだライン |
| 1 | 石 3 個。単色なら**既存リーチ**、混色なら死んでいる | ラベルとして表現される |
| 2 | 石 2 個。`G_A2` より必ず異色 | 死んだライン |
| 3 | — | **補題 N1 より存在しない** |
| 4 | 石 0 個。**全空きライン** | 位置は形状だけで決まる |

石は取り除かれないので、死んだラインは以後も死んだままである(補題 3)。
よって以後リーチが生じうるのは「既存リーチ(= ラベル)」と「全空きライン」だけであり、
全空きラインの集合は空きマス集合、すなわち形状だけで決まる。
以後のゲームは「形状の上に石を積み、自分のラベルの付いたマスを埋めたら勝ち、
全空きライン上に 4 個並べたら勝ち」という規則に完全に一致する。∎

**検証.** `reduced_verify.cpp` の `check` モードで、実盤面の厳密解と還元モデルの値を突合した。

| turn | 検査局面数 | 不一致 |
|---|---|---|
| 57 | 3,936 | **0** |
| 55 | 2,390 | **0** |
| 53 | 2,182 | **0** |
| 51 | 1,733 | **0** |

> **系 N7(`m* = ∞` におけるラベルの完全分類)**
> 制約(C) ∧ `G_A2` ∧ `G_T` ∧ `m* = ∞` のとき、ラベルは次の場所にしか存在しえない。
>
> | 場所 | 条件 | 色 |
> |---|---|---|
> | `K` の段2 | `h(K) = 4` | **黒**のみ |
> | `K` の段3 | `h(K) = 4` | **白**のみ |
> | 段4 | `h = 2` または `h = 4` の柱 | **黒**のみ |

**証明.** 高さ `h` の柱の即置可能マスは段 `5 − h`(補題 2)。補題 N1 より `h ∈ {0,1,2,4}` なので
即置可能マスの段は `h=1 → 段4`、`h=2 → 段3`、`h=4 → 段1` のいずれか。よって埋没した空きマスは
`h=2` の柱の段4、`h=4` の柱の段2・段3・段4 に限られる。制約(C) より即置可能マスにラベルは無い。
`m* = ∞` より有効脅威(白の段2・段4、黒の段3)は存在しないので、残るのは上表の 3 種である。∎

これは論文 補題 17・18 の完全版にあたる。**白のラベルは高々 1 個(`K` の段3)**しか存在しえない。

## 3. 完全検証の方法

定理 N6 と系 N7 により、`m* = ∞` の場合の推測 2 は次の有限問題になる。

> 各形状について、系 N7 で許される**すべてのラベル割当**で還元ゲームの値が引き分けか?

ラベル割当は最大 `2^(|{h=2}| + 3)` 通りあるが、論文の**補題 16(ラベル単調性)**を 2 回使えば
**1 形状あたり 2 回の求解**に落ちる。

- **(A)** 白のラベルを最大(= `K` の段3)・黒を空 にして解く。ここで白が勝てなければ、
  黒のラベルをいくら足しても白は勝てない(黒ラベルの追加は白の値を改善しない)。
- **(B)** 黒のラベルを最大・白を空 にして解く。ここで黒が勝てなければ、どのラベル割当でも黒は勝てない。

(A)(B) がともに「勝てない」なら、その形状に載るすべての局面が引き分けである。

**この近道の妥当性も機械検証した。** `E ≤ 8` について**全ラベル割当を直接列挙**した結果、
近道による判定と完全に一致した(下表)。

**完全に反例ゼロ**で、`E` が奇数(= **白番**)の `E = 11, 13, 15` にだけ反例が出る。

ただし `E = 18` / `E = 20`(いずれも黒番)にも反例があるので、
「黒番なら安全」という単純な規則にはならない。

`E = 12`(turn 53)が反例ゼロなのに `E = 11` と `E = 13` には反例があるので、
「turn が下がるほど危険」という単調性は成り立たない。**turn 54 という上端が本質的**である。

**注目すべき点**: 見つかった反例は**すべて白の勝ち**であり、**黒が勝つ形状は 1 つも見つかっていない**。
これは論文の理論と整合する。創出で生じるリーチは必ず段4 にあり(補題 13 + `G_3`)、
`owner(4) = 白` なので**白の創出だけが有効脅威になる**からである。
黒にとって創出は無効脅威にしかならず(補題 19 の精神)、勝ちには結びつかない。

> **系 N10(外れ方は一方向)**
> 検証範囲において、ゲートを通過した局面で R2 が外れるのは
> 「R2 = 引き分け、実際は**白**の勝ち」という一方向の取りこぼしだけである。
> R2 が勝敗を断定して外れた例(誤断定)は 1 件も無く、定理 9 と整合する。

全空き H4 ラインが 0 本・1 本の形状で反例が 0 なのは、
論文の**定理 13(単一ラインの創出不能性・証明済)**そのものである。
そこで次のゲートを導入する。

> **定義(ゲート `G_X`)**: 全空き H4 ライン(4 柱とも非満杯な段4 の水平線)のうち、
> **柱を共有する 2 本の組が存在しない**。

> **定理 N11(`G_X` による厳密性の回復)**
> 制約(C) ∧ `G_A2` ∧ `G_T` ∧ `G_3` ∧ `G_X` の下では、**turn によらず 厳密解 = R2** である。
> しかも `G_X` を課すと **`E ≤ 18`(turn ≥ 47)**しか起こりえない。

**検証**: `G_X` を満たす**全形状**(全 E)を尽くし、白勝ち・黒勝ちともに 0(`gx_E*.log`)。

| E | turn | `G_X` を満たす形状数 | 白勝ち | 黒勝ち |
|---|---|---|---|---|
| ≤ 10 | ≥ 55 | (`G_X` 無しでも 0。定理 N9) | 0 | 0 |
| 11 | 54 | 231,552 | **0** | 0 |
| 12 | 53 | (`G_X` 無しでも 0) | 0 | 0 |
| 13 | 52 | 194,024 | **0** | 0 |
| 14 | 51 | 122,636 | **0** | 0 |
| 15 | 50 | 54,752 | **0** | 0 |
| 16 | 49 | 15,657 | **0** | 0 |
| 17 | 48 | 1,848 | **0** | 0 |
| 18 | 47 | 264 | **0** | 0 |
| ≥ 19 | ≤ 46 | **0**(`G_X` を満たす形状が存在しない) | — | — |

`E ≥ 19` で `G_X` を満たす形状が 1 つも無いのは、非満杯な柱が多くなると
どうしても交差する全空き H4 ラインの組ができてしまうためである(列挙で確認)。
すなわち **`G_X` を課すと自動的に turn ≥ 47 になる**。

**証明の見通し**(完全な手証明は今後の課題):
4×4 のグリッドにおいて、行と列、行と対角、列と対角は必ず交わり、
2 本の対角線どうしと、相異なる行どうし・列どうしは交わらない。
したがって `G_X` の下で全空き H4 ラインの族は「平行な行の集まり」「平行な列の集まり」
「2 本の対角線」「高々 1 本」のいずれかであり、**互いに素**である。
すると攻撃側のどの 1 手も全空き H4 ラインを高々 1 本しか伸ばせないので、
守備側は論文の定理 13 の議論を各ラインに独立に適用でき、
どのラインにも 2 石すら並べさせずに済む。論文が定理 13 の先に進めなかったのは
まさに「1 手が最大 3 本を同時に伸ばす」交差の場合だけだったので、それを除けば議論が閉じる。

### 4.3 黒は創出では勝てない —— 片側の限界値

掃引では **「黒が勝てる形状」が 1 つも現れなかった**(`E ≤ 16` は全形状で確定、
`E ≤ 18` は `G_X` つきで確定、`E = 17…20` は掃引の範囲で 0)。
これは理論的にも自然である。`G_3` の下で創出できるリーチは必ず段4 にあり(補題 13)、
`owner(4) = 白` なので**黒にとっては常に無効脅威**にしかならないからである。

> **系 N12(片側の限界値。実装に直接効く)**
> 制約(C) ∧ `G_A2` ∧ `G_T` ∧ `G_3` かつ `m* = ∞` のとき、厳密値は
> **「引き分け」か「白の勝ち」のいずれか**である(`E ≤ 16` は全形状で確定)。すなわち
> - **黒番なら 値 ≤ 0**(黒は勝てない)
> - **白番なら 値 ≥ 0**(白は負けない)
>
> したがって turn ≤ 54 でも R2 = 0 を**片側の限界値**として αβ 探索に使える。
> 厳密値としては使えなくても、**黒番での fail-low カット / 白番での fail-high カット**は正当である。

これは論文 §12.4 の「断定したときだけ信じる」運用を、
**引き分け判定のときにも(片側だけ)使える**ように拡張するものである。
なお `G_T0`(高い柱 0 本)のとき論文 定理 5 は抽象モデルで同じ結論(黒は勝てない)を出すが、
反例 B が示すとおり**白の側は創出で勝ててしまう**ので、退化形 `rW & mask_4` は厳密ではない。
系 N12 はその「黒側だけは正しい」という部分を切り出したものにあたる。

## 5. 反例

### 5.1 反例 A —— 最小の反例(turn 54、盤上にリーチが 1 個も無い)

```
    z=1  z=2  z=3  z=4
y=4 XXOO XOOX O-XX X-OX
y=3 XXXO OOXX X-OO X-OX
y=2 OOXX XXOO OX-- ----
y=1 OOXO OXXO XOOX O-XO
  x=1234 1234 1234 1234        (X = 黒, O = 白, - = 空き)
```

- turn = 54(**白番**)、`E = 11`
- 柱の高さ: (x2,y1)=1, (x1,y2)=1, (x2,y2)=1, (x3,y2)=2, (x4,y2)=2, (x2,y3)=2, (x2,y4)=2
- ゲート: `G_A2` = OK, `G_T`(高い柱 0 本)= OK, `G_3` = OK, 制約(C) = OK
- **盤上にリーチが 1 個も無い**。したがって `m* = ∞`、**R2 = 引き分け**
- **厳密解 = 白の勝ち**
- 交互着手と重力で**到達可能**(手順は `verify_counterexamples.txt` に出力)

最善手順(白から):

```
白(x2,y2,段4) 黒(x3,y2,段3) 白(x2,y1,段4) 黒(x4,y2,段3) 白(x1,y2,段4) 黒(x2,y3,段3)
白(x3,y2,段4) 黒(x4,y2,段4) 白(x2,y3,段4) 黒(x2,y4,段3) 白(x2,y4,段4)*勝ち
```

**機構**: 全空きの H4 ラインが 2 本ある。
行 y=2 の段4 `{(x1,y2),(x2,y2),(x3,y2),(x4,y2)}` と、列 x=2 の段4 `{(x2,y1),(x2,y2),(x2,y3),(x2,y4)}`。
両者は **(x2,y2) で交差**している。白は交点から打ち始め、
黒が 2 本のうち 1 本しか消火できないことを突いて、最後は列 x=2 の段4 を 4 個そろえた。
まさに論文が「証明が残っている」としていた**交差ケース**そのもので、しかも
**攻撃側が勝てる**という結論だった。

### 5.2 反例 B —— `G_T0`(平坦盤)でも起こる(turn 45)

```
    z=1  z=2  z=3  z=4
y=4 OOXX XXOO X-O- ----
y=3 OOXO XXOO OXXX ----
y=2 OOXX XXOX --XO ----
y=1 XXOO OOXX OOXO ----
  x=1234 1234 1234 1234
```

- turn = 45(**黒番**)、`E = 20`
- ゲート: `G_A2` = OK、**高い柱 0 本 = `G_T0` まで成立**、`G_3` = OK、制約(C) = OK
- 盤上のリーチは黒の段4 が 2 個(いずれも埋没・無効脅威)のみ → `m* = ∞`、**R2 = 引き分け**
- **厳密解 = 白の勝ち**、到達可能

黒は自分の 2 個の無効な段4 リーチをテンポに使うが(論文 補題 19 のとおり)、
その代償に白へ段4 の石を 2 個ただで与えてしまい、最終的に白が**段4 の対角線**
`(x1,y4)-(x2,y3)-(x3,y2)-(x4,y1)` をそろえて勝つ。

**この例の意味**: 論文 §12.5 は「`G_T0` なら R2 は `rW & mask_4` の 1 判定に退化する」と述べている。
定理 5(平坦盤定理)は**抽象モデル**の定理なので誤りではないが、
**実盤面では創出があるためこの退化形は厳密ではない**。低 turn で `G_T0` の通過率が高い
(論文は turn 57〜51 で 33% 前後と報告)ことを踏まえると、この点は実装上重要である。

### 6.2 壊れていない箇所

### 6.3 実装への提言

論文 §12.2 の `endgame_gate()` は **`turn >= 55` まで安全に広げられる**。ただし
turn 57 以下では `G_3` が必要になるので、次の形にする。

```cpp
static inline bool endgame_gate(const BoardInc &b, int turn)
{
    if (turn >= 63) return true;                                            // ゲート不要
    if (turn >= 61) return endgame_gate_A (b.cnt);                          // 定理 12
    if (turn >= 58) return endgame_gate_A2(b.cnt) && tall_columns_le1(b);   // 定理 11・12
    if (turn >= 55) return endgame_gate_A2(b.cnt) && tall_columns_le1(b)    // 定理 N9(本研究)
                        && endgame_gate_3(b);
    return false;                                                            // turn <= 54 は反例あり
}
```

`turn <= 54` では **R2 を厳密値として使ってはならない**。使うなら
定理 9 に基づく「断定時のみ即 return」に限る(§12.4 の運用)か、系 N12 の片側カットに限る。

**速度面の期待値は控えめに見ておくべきである。** 論文 §12.3 のとおりゲート通過率は
turn 59 で 3.7%、turn 58 で 1.3% と急落しており、turn 55〜57 ではさらに下がる。
turn 58 → 55 の拡張で得られるノード削減はおそらく僅かで、
**この拡張の主な価値は「評価関数の正しさの下限が理論的に確定した」ことにある**
(論文 §12.3 末尾の指摘と同じ位置づけ)。
実装に入れる前に `-DBENCH` のノード数で費用対効果を測るべきである。

なお定理 N4 より、`turn <= 38` ではゲートが**原理的に通らない**ので、
`turn <= 38` は無条件で `false` を返してよい(判定コストの節約)。

**さらに広げたい場合**は `G_X`(定理 N11)を追加すれば turn 47 まで厳密にできる。
`G_X` は「非満杯な柱だけからなるグリッドライン(= 全空き H4 ライン)を 10 本ぶん求め、
そのうち 2 本が柱を共有していないか」を見るだけで、段4 の 16 bit から
行・列・対角の 10 ビットを畳んで求められる。判定コストは `G_3` と同程度である。
ただし通過率(= 追加でどれだけ刈れるか)は未計測なので、
**採否は実測での費用対効果しだい**である。定理 N11 自体はまだ手証明が無く、
全形状の完全検証に依拠している点にも注意。

```cpp
    if (turn >= 47) return endgame_gate_A2(b.cnt) && tall_columns_le1(b)     // 定理 N11(未証明・完全検証のみ)
                        && endgame_gate_3(b) && endgame_gate_X(b);
```

## 7. 残った課題

1. **定理 N11(`G_X` で厳密性が回復する)の手証明。** 完全検証は済んでいるが証明は無い。
   §4.2 の見通し —— 「`G_X` の下で全空き H4 ラインは互いに素 ⟹ 攻撃側の 1 手は高々 1 本しか伸ばせない
   ⟹ 論文の定理 13 を各ラインに独立適用できる」—— を詰めれば書けると思われる。
   これができれば、論文の定理 12 の範囲は「turn ≥ 58」から「`G_X` つきで全 turn」に置き換わる。

2. **`E ≥ 17` の反例個数の完全な地図。** `E ≤ 16` は完全掃引済み、
   `E = 17 … 20` は反例の存在まで、`E ≥ 21` は未検証である(§4.1)。
   求解コストが `E` ごとに約 2.9 倍になるので、そのまま尽くすのは現実的でない。
   還元モデルにさらに論文の還元定理(定理 3)を組み込んで代表形に落とせば届く可能性がある。

3. **手番による規則性の説明。** `E = 12, 14, 16`(黒番)が完全に反例ゼロで
   `E = 11, 13, 15`(白番)にだけ反例が出る、という強い規則性の理由が未解明である。
   一方 `E = 18, 20`(黒番)には反例があるので、単純な手番の規則ではない。
   ここを説明できれば「黒番なら turn をもっと下げてよい」という実用的なゲートになりうる。

4. **`G_X` の実局面での通過率。** 実装に採るかどうかはこれで決まる。
   本研究の標本は形状の一様分布なので、探索木に現れる分布とはずれている。

5. **推測 3(規則 R3)・推測 4・推測 5・推測 6 は未着手。** 本研究は課題 1 に集中した。
   ただし定理 N6(還元定理)は推測 5(`G_T0` 下の創出込み平坦盤定理)にもそのまま使えるので、
   同じ手法で完全検証できる見込みが高い。なお反例 B は `G_T0` を満たすが、
   勝つのは白なので推測 5(「黒は勝てない」)の反例ではない。

6. **`m* < ∞` 側の完全検証。** 定理 N9 の証明は `m* < ∞` の部分を論文の定理 9 に依存している。
   還元モデルで有効脅威を含む全ラベル割当を尽くせば、定理 9 にも依存しない完全な検証になる。
