## 0. 結論

**(1) 予想 B′ は偽である。しかもその原因は `G_A2` を外したことそのものだった。**

予想 B′ は「`G_A ∧ G_T ∧ G_bd` の下で、創出に使えるラインは即置可能マスを 2 個以上持つ」だった。
これは **補題 B(H4 ラインの高さ 2 以上の柱は高々 2 本)と同値**であり、
補題 B の証明は `G_A2` を本質的に使っている(§1)。`G_A` だけだと `k = 3` の配置が通り、
そのとき H4 ラインの即置可能マスは **高々 1 個**になる。**予想 B′ は成立しない。**

**(2) 定理 F は 定理 N から 2 行で証明できる。創出込みの拡張も見通しが立った。**

新しい 定理 N(下記)から「`G_T0` では押し返し用の**奇数スタック**が存在しない」が直ちに従い、
定理 F(平坦盤では黒は勝てない)が出る。創出込みでも、黒が奇数スタックを**作ることはできない**
(`G_T0` の下で段3 のマスは常に即置可能なので埋没スタックにならない)。
したがって創出で黒が勝つ道は **(i) 白をゲートに打たせる / (ii) 直接二重脅威** の 2 本だけであり、
`G_bd` と `G_C` がそれぞれの入口に対応することが理論的に説明できた(§2)。

**(3) 【本命】高い柱が 2 本以上でも使える規則 R3 を作り、E ≤ 13 で完全一致を確認した。**

> **定理 N(解放数定理)**: 抽象モデルで**各柱のラベル付きマスが高々 1 個**のとき、局面の値は
> - 中立マスの総数 **N の偶奇**と手番(= どちらが「詰まる側」P か)
> - 各色の脅威の **解放数 ρ = 4 − λ の偶奇**の本数(λ = 脅威の段)
> - 双方毒(BW)脅威の有無
>
> だけで決まる。そして **ρ が奇数 ⟺ λ = 3**。すなわち
>
> > **段3 の脅威だけが、ツークツワンクの手番を相手に押し返せる。**
> > 段2 の脅威(ρ = 2)と段4 の脅威(ρ = 0)は押し返せない。

これが **構造定理の「高い柱 2 本」という閾値の本当の理由**である。
段3 の埋没脅威を持てるのは高さ 3 以上の柱だけなので、**高い柱が 1 本なら押し返しは高々 1 回**、
2 本あると**押し返し合戦**が起きて R2 が破れる。

この定理から規則 **R3** が定義でき、`abstract_r3.cpp` で
**E ≤ 13 の全 97,951 パターン(高い柱 0〜4 本)で厳密解と完全一致**した。
同じ標本で R2 は 11,220 パターン(11.5%)を外している。

| 高い柱の本数 | パターン数 | **R2 の不一致** | **R3 の不一致** |
|---|---|---|---|
| 0 | 14,557 | 0 (0.00%) | **0** |
| 1 | 24,957 | 0 (0.00%) | **0** |
| **2** | 26,106 | **3,184 (12.20%)** | **0** |
| **3** | 24,099 | **5,544 (23.01%)** | **0** |
| **4** | 8,232 | **2,492 (30.27%)** | **0** |
| 合計 | 97,951 | 11,220 | **0** |

**残る制限は「各柱のラベルは高々 1 個」**である(§3.5)。

## 1. 予想 B′ は偽

### 1.1 予想 B′ ⟺ 補題 B

`_ゲート緩和の検討.md` §4.2 の 予想 B′ は次のものだった。

> **予想 B′**: `G_A ∧ G_T ∧ G_bd` の下で、創出に使える生きたライン L はいずれも
> 「攻撃側が石を置く必要のあるマス」のうち 2 個以上が即置可能である。

H4 ラインについてこれは **補題 B**(`_turn57以下の証明.md` §4)と同じ主張である。
補題 B は「H4 ラインの 4 柱のうち高さ 2 以上のものは高々 2 本(k ≤ 2)」を主張し、証明は 2 行だった:

- k = 4 は `G_3` が禁じる(段3 が 4 マスとも空のライン)
- **k = 3 は `G_A2` が禁じる**(段3 のラインが「1 石 + 空き 3」になるため)

### 1.2 反例 — `G_A` だけだと k = 3 が通る

`G_A` は「2 石 + 空き 2」しか禁じないので、**k = 3 の配置がそのまま残る**。
一直線に並ぶ 4 本の柱の高さが例えば `(3, 2, 2, 1)` のとき:

| 柱 | 高さ | 段4 のマス | 即置可能か |
|---|---|---|---|
| C1 | 3 | 空き | ✗(段2 が即置可能マス) |
| C2 | 2 | 空き | ✗(段3 が即置可能マス) |
| C3 | 2 | 空き | ✗ |
| C4 | 1 | 空き | **✓** |

段4 の水平ラインは 4 マスとも空(全空き H4 ライン)だが、**即置可能なのは C4 の 1 マスだけ**である。
`G_T` は満たされている(高い柱は C1 の 1 本)。`G_3` も満たされている
(段3 が空なのは C1・C2・C3 の 3 本で、4 本組になっていない)。
`G_bd` は埋没リーチの配置しだいで満たせる。**したがって 予想 B′ は偽である。**

さらに極端な例として、4 柱の高さが `(0, 2, 2, 2)`(1 本は満杯)なら
H4 ラインは空き 3 個で **即置可能マスは 0 個**になる。

> **系**: 予想 B′ が成り立つのは実質的に `G_A2` を課したときだけである。
> `_ゲート緩和の検討.md` §4.2 で「予想 B′ が示せれば厳密性まで言える」と書いたが、
> **それは `G_A2` を課すことと同義**であり、緩和にはならない。
> `G_A ∧ G_T ∧ G_bd` が実測で**健全**(誤断定 0)なのは別の理由による(§2 の構造がヒントになる)。

## 2. 定理 F の創出込み拡張

### 2.1 定理 N による 定理 F の再証明

定理 N(§3)を認めると 定理 F は 2 行で出る。

**証明.** `G_T0`(すべての柱の高さ ≤ 2)では埋没マスは段4 だけなので、
すべての脅威の解放数は `ρ = 4 − 4 = 0`(偶数)である。
よって**どちらの色も奇数スタックを持たない ⟹ ツークツワンクの手番は決して押し返せない**。
最初に詰まる側 P は、自分のスタックを燃やし尽くしたあと相手のゲートを踏むしかない。
そして `N ≡ E (mod 2)` と `E = 65 − turn` から **P は必ず黒**である(`_ゲート緩和の検討.md` §3.1)。
したがって黒は勝てない。∎

### 2.2 創出で黒は「奇数スタック」を作れるか

創出込みに拡張する鍵は次の観察である。

> **補題 F4**: `G_T0` の下では、**創出によって奇数スタック(= 段3 の埋没脅威)を作ることはできない。**

**証明.** 奇数スタックとは段3 にある**埋没**リーチのことである。
段3 のマスが埋没する ⟺ その柱の高さが 3 以上(補題1)。`G_T0` はこれを禁じている。
`G_T0` は着手で壊れない(高さは減るだけ)ので、対局中も段3 のマスは常に即置可能である。∎

即置可能なマスに生じたリーチは、その場で相手が塞ぐので**スタックにならない**。
塞いだ結果その上の段4 のマスが開くが、そのマスが無ラベルなら**もともと中立マスとして N に数えられている**ので、
交換は「中立マスを双方 1 個ずつ消費する」だけで終わる(`_turn57以下の証明.md` 系 C3 と同じ)。

### 2.3 したがって黒の勝ち筋は 2 本しかない

> **補題 T1″(補題 T1′ の理論的裏づけ)**: `G_T0` の下で黒が勝つには次のどちらかが要る。
>
> - **(i) ゲート踏ませ**: 段4 のマスが**ラベル付き**の柱では、その段3 のマスは中立マスではなく**ゲート**である。
>   黒がそこにリーチを作れば白はゲートを踏まされ、黒のスタックなら黒が勝つ。
>   → 入口は「ゲート(= `b_d`)にリーチを作れること」。**`G_bd` が塞ぐ。**
> - **(ii) 直接二重脅威**: 1 手で即置可能マスに 2 個のリーチを作れば白は片方しか塞げない。
>   ツークツワンクとは無関係な純粋な戦術。→ 入口は「1 手でリーチを作れること」。**`G_C` が塞ぐ。**

補題 F4 が「第三の道は無い」ことを保証しているのが要点である。
`_ゲート緩和の検討.md` の 補題 T1 が (ii) を見落としていたのは、
「押し返し」と「二重脅威」を区別していなかったためである。

### 2.4 定理 F′ の現状

> **定理 F′(候補・未証明)**: `G_T0 ∧ G_bd ∧ G_C` ならば黒は勝てない。
> 実測: 6,878 局面すべてで黒勝ち 0・誤断定 0(`_追補_柱の本数と創出.md` §2.3)。

補題 T1″ により、証明に必要なのは次の 1 点だけに絞られた。

> **残る課題**: `G_C` は**ゲート判定時点で** 1 手創出を禁じるだけである。
> 数手進んだあとに「2 石 + 空き 2」のラインができて二重脅威が組めないことを示す必要がある。
> `G_T0` の下で創出に使えるラインは
> **段3 の水平線・段4 の水平線・垂直線・斜め線(いずれも空きは高々 2 個)** に限られる
> (`_追補_柱の本数と創出.md` §3 の分類)ので、
> **「2 手で二重脅威を組めるか」という有限の問題に落ちている。**

## 3. 定理 N(解放数定理)と規則 R3

### 3.1 柱を「中立マス + ゲート + 脅威 + 解放マス」に分解する

抽象モデルの柱 j(高さ h、ラベル付きマスが下から i 番目 = 段 λ = 5 − h + i)を次のように分解する。

```
      段4  ┐
       …   ├ 解放マス  (4 − λ) 個 = ρ         ← 脅威が解決したあとに開く
      λ+1  ┘
      λ    ■ 脅威マス(色 X のリーチ)
      λ−1  ● ゲート                            ← ここを踏むと相手に取られる
       …   ┐
      5−h  ├ 中立マス  (i − 1) 個 = λ + h − 6
           ┘
```

ラベルの無い柱は h 個ぜんぶ中立マスである。中立マスの総数を **N** と書く。

> **補題 N1(ゲートの毒は色だけで決まる)**: 色 X の脅威を持つ柱のゲートは、
> **有効脅威か無効脅威かによらず `opp(X)` にとって毒**であり、X は自分から踏んで潰せる(= burn)。

**証明.** 補題 Q(`_turn57以下の証明.md` §2.2)より、ゲートを F 偶数で踏むと最初の**有効**脅威が、
F 奇数で踏むと最初の**無効**脅威が発火する。
- X の脅威が有効(X = owner(λ))なら、F 偶数で踏む側は owner(λ−1) = `opp(X)` で、勝つのは owner(λ) = X。
  F 奇数で踏む側は X 自身で、無効脅威が無いので素通り(= burn)。
- X の脅威が無効(X = opp(owner(λ)))なら、F 奇数で踏む側は owner(λ) = `opp(X)` で、
  勝つのは opp(owner(λ)) = X。F 偶数で踏む側は X 自身で素通り(= burn)。

いずれも「踏んで負けるのは `opp(X)`、素通りできるのは X」である。∎

**補題 N1 が意味すること**: 脅威の**段は毒の向きに影響しない**。段が効いてくるのは次の 1 点だけである。

> **補題 N2(burn は ρ 個の中立マスを解放する)**: X が自分のゲートを踏むと、
> 相手が脅威マスを塞いで 2 マスが消費され、**手番は X に戻る**。
> このとき脅威マスより上の **ρ = 4 − λ 個のマスが新たに中立マスとして開く**。

### 3.2 縮約ゲーム

以上より、抽象モデルは次の小さなゲームに縮約される。

- **中立マスのプール N**。両者が交互に消費する(burn は手番を変えないので、消費は厳密に交互)。
- 各色の**スタック**(= 脅威を持つ柱)。自分のスタックは burn でき、burn すると N が ρ 増えて手番は自分に戻る。
- **双方毒スタック**(BW)は誰も burn できない純粋な毒。
- 相手のスタックのゲートを踏んだら負け。プールもスタックも尽きて毒だけが残ったら踏むしかない。

> **補題 N3(押し返し)**: プールが尽きて手番が回ってきた側(= 詰まる側 P)が
> **ρ が奇数のスタックを burn すると、詰まる側が相手に移る**。ρ が偶数なら P は詰まったままである。

**証明.** P が burn すると N = ρ で P の手番。プールは交互に消費されるので、ρ 個を消費し終えた時点の手番は
ρ が偶数なら P、奇数なら相手。∎

> **系 N4**: `ρ = 4 − λ` が奇数 ⟺ `λ = 3`(λ ∈ {2,3,4} なので λ=3 のみ)。
> **段3 の脅威だけが押し返せる。**
> そして段3 の埋没マスを持てるのは高さ 3 以上の柱だけ(補題1)なので、
> **押し返しの回数 = 高い柱の本数**でおおよそ決まる。

### 3.3 規則 R3

```
R3(局面):
  N ← Σ(ラベル無しの柱の高さ) + Σ(ラベルありの柱の「ゲートより下の中立マス数 λ+h-6」)
  o[色] ← 解放数 ρ が奇数(= 段3)の脅威の本数
  e[色] ← 解放数 ρ が偶数(= 段2 / 段4)の脅威の本数
  γ     ← 双方毒の脅威の本数
  詰まる側 P ← (N が偶数なら手番、奇数なら相手)
  return 縮約ゲームの解(P, o, e, γ)

縮約ゲームの解(詰まる側 s, o, e, γ):
  if s にスタックが無い:
       相手にスタックか γ があれば「相手の勝ち」、無ければ「引き分け」
  s は自分のスタックを 1 本 burn する(自分に最も良い結果を選ぶ):
       奇数スタックを burn → 詰まる側が相手に移る
       偶数スタックを burn → 詰まる側は s のまま
```

縮約ゲームはスタックの本数しか状態に持たないので、**数十ステップで解ける**。

### 3.5 残る制限 — 各柱のラベルは高々 1 個

R3 は「1 本の柱に脅威が 2 個以上ある」場合を扱えない。
その場合は連続したラベルの**連鎖(run)**になり、補題 Q より
「F 偶数で踏むと最初の**有効**脅威、F 奇数で踏むと最初の**無効**脅威が発火する」という
**パリティ依存の挙動**になる。補題 N1 の「毒の向きは色だけで決まる」が成り立たなくなる。

拡張の方針は次のとおり(未実装):

1. 柱ごとに `winEven`(F 偶数で踏まれたときの勝者、または「素通り」)と `winOdd` を計算する。
   単一ラベルの場合は「有効脅威 → (winEven, winOdd) = (X, 素通り)」「無効脅威 → (素通り, X)」となり、
   どちらも補題 N1 に一致する。
2. 素通りの場合の消費マス数(1 + run の長さ)と、その上に残る次の run を再帰的に扱う。
3. 縮約ゲームの状態に「パリティ依存スタック」を追加する。

実盤面での影響: 1 本の柱に埋没リーチが 2 個以上あるのは、**高さ 3 以上の柱**に限られる。
`G_T`(高い柱が高々 1 本)の下では**高々 1 本の柱でしか起こらない**ので、
上の拡張は「1 本ぶんの run を場合分けする」だけで済むはずである。

### 3.6 実装コスト

R3 の判定に必要なのは、局面から

- 各柱の高さ(`~occ & mask_k` の popcount で取れる)
- 各リーチマスの段(`reach()` は葉で既に計算済み)
- そこから N の偶奇・`o[]`・`e[]`・γ

を作ることだけで、`cnt[]` の走査は要らない。**段パリティ規則 R2 の判定に数十命令を足す程度**である。
ただし R3 が価値を発揮するのは「創出が起きない」ことが保証されている局面に限られるので、
**ゲート(`G_A2` 等)は依然として必要**であり、通過率の問題は解決しない。
R3 の意義は次の 2 点にある。

- **`G_T` を外せる。** ゲートから `tall_columns_le1()` を削れる。通過率は turn 57 で 84.7% → 100%、
  turn 50 で 40.1% → 100% に上がる(`_追加検証.md` §2.4)。
- **構造定理の閾値の理由が判明した。** 「高い柱 2 本」は段3 の脅威が 2 個持てる境目である。
